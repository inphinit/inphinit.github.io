Apache

Aprenda a configurar um servidor web Apache (por exemplo, XAMPP, LAMP, MAMP, WAMP).

Configurando Apache

Para configurar o servidor web Apache, você pode utilizar o seguinte exemplo de configuração:

<VirtualHost *:80> DocumentRoot /var/www/html/my-app <Directory /var/www/html/my-app> AllowOverride All </Directory> ErrorLog ${APACHE_LOG_DIR}/error.log CustomLog ${APACHE_LOG_DIR}/access.log combined </VirtualHost>

Não aponte para o diretório ./public; você deve apontar para a raiz do projeto, como no exemplo.

Usando o projeto como um subdiretório

É possível utilizar o Inphinit como um diretório no Apache (por exemplo, http://localhost/my-app/), simplesmente instalando ou movendo o projeto para a pasta do Apache, conforme mostrado nestes exemplos:

  • /var/www/html/my-app
  • C:\xampp\htdocs\my-app
  • C:\wamp\www\my-app
